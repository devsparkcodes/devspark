# UI/UX Specification

## Objective
Build a premium, memorable technology-company website that encourages exploration while remaining clear, fast, accessible and trustworthy.

## Workflow
1. Inspect approved logo and requirements.
2. Use UI UX Pro Max to research styles/layouts/typography.
3. Propose a concise design direction and tokens.
4. Build one strong homepage concept.
5. Review desktop/mobile screenshots.
6. Get user feedback before expanding the full design.
7. Update docs/tokens after approved visual decisions.

## Experience
- Distinctive hero and clear CTAs.
- Clear distinction between Solutions and Courses.
- Intuitive navigation, readable hierarchy and consistent components.
- Refined hover/focus states and useful micro-interactions.
- Intentional mobile layout, not just a compressed desktop layout.
- High-quality footer and next steps.

## 3D and motion
User is open to 3D. Explore one primary interactive/3D concept before adding effects everywhere. Choose a library only after assessing need. Keep initial content usable while effects load; respect reduced-motion preferences; avoid layout shifts; provide mobile fallbacks; optimize assets.

## Tokens
Centralize colors, typography, spacing, radii, shadows, container widths and motion values. Palette and fonts are provisional.

## UI UX Pro Max skill
Official repository: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

The repository documents OpenCode support and this install command:
```bash
npx ui-ux-pro-max-cli init --ai opencode
```
Python 3.x is listed as a prerequisite for its search script. Verify current official instructions and installed version before installation.

Use the skill as guidance only. It must not override confirmed requirements, invent content, change the stack without approval, add excluded products or sacrifice usability for effects.

## Review checklist
- Desktop/mobile hero clearly communicates DevSpark.
- Logo is crisp and undistorted.
- Contrast and typography are readable.
- Buttons and navigation work with mouse, touch and keyboard.
- Reduced motion is respected.
- No fake content, dead links or filler pages.
- Solutions and Courses are easy to find.
